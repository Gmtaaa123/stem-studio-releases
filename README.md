# STEM Studio — bản dùng thử cho giáo viên

Kho này chỉ phân phối bộ cài Windows/Android và thông tin cập nhật. Mã nguồn được quản lý ở kho riêng.

- [Tải bản 0.2.0-beta](https://github.com/Gmtaaa123/stem-studio-releases/releases/tag/v0.2.0-beta)
- Windows 10/11 x64: chọn **x64-setup.exe** hoặc **.msi**.
- Android 7 trở lên: chọn **.apk**; không cài trực tiếp file .aab.
- Hướng dẫn cài đặt và thông báo giấy phép được đính kèm bản phát hành.
- Góp ý: dùng [Issues](https://github.com/Gmtaaa123/stem-studio-releases/issues). Không gửi thông tin học sinh hoặc tài liệu riêng tư.

Đây là bản beta. Cần sao lưu tài liệu .stem. Cài APK trên thiết bị Android thật hiện chưa nghiệm thu.
